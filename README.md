# Portfólio — Gustavo Ignácio

Portfólio pessoal desenvolvido para apresentar projetos, formação, currículo e formas de contato. A interface utiliza um tema dark moderno, é responsiva e possui suporte global a Português e Inglês.

## Tecnologias

- HTML5
- CSS3 responsivo
- JavaScript Vanilla
- Font Awesome
- Devicon
- Formspree
- Vercel

## Destaques da interface

- Cabeçalho com efeito de transparência e blur durante a rolagem
- Menu mobile acessível
- Animações suaves de entrada e microinterações
- Tema dark com gradientes, cards e efeitos de profundidade
- Alternância PT/EN persistida no navegador
- Carrossel de projetos com botões, indicadores, contador, teclado e swipe
- Respeito à preferência `prefers-reduced-motion`
- Formulário de contato com validação e feedback visual

## Executando localmente

```bash
git clone https://github.com/keijizn/Portifolio.git
cd Portifolio
```

Depois, abra `index.html` no navegador ou use uma extensão/servidor local como Live Server.

## Deploy

O projeto está preparado para deploy estático na Vercel por meio do arquivo `vercel.json`.
Link para o site: https://portifolio-z2ih.vercel.app
